# Base44 handoff documents

These documents were recovered from the `arcange-crossdiag-v1.0.0-rc.2` source-recovery archive and describe how to
build a hosted web companion (**Arcange CrossDiag Cloud**) alongside the native desktop application.

- `BASE44_START_HERE.md` — first steps and what the package contains.
- `BASE44_MASTER_PROMPT.md` — prompt for the Base44 app builder.
- `BASE44_ARCHITECTURE_AND_MIGRATION.md` — which responsibilities stay local and which move to the cloud.
- `BASE44_DATA_MODEL.md` — proposed cloud entities, fields and permissions.

Path note: the archive referenced the desktop source as `desktop-source/arcange-crossdiag-v1.0.0-rc.2/`. That source
now lives at the repository root, so read those references as the repository root.
